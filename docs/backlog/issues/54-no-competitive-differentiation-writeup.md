# 54. No competitive/differentiation write-up vs. other browser snake-likes

**Type:** gtm
**Priority:** p3
**Labels:** gtm, priority: p3

## Summary

The game has several features that go meaningfully beyond a typical browser snake clone —
first-person view toggle, per-level objectives, an enemy/AI system, a real level-authoring
pipeline via the Copilot canvas editor — but there's no single document laying out how this
compares to other browser snake-likes, or what the actual pitch is for someone deciding whether to
play or share it.

## Expected

A short competitive/differentiation write-up: what makes this version distinct (first-person mode,
objective variety, the level editor), targeted at whoever is deciding whether to feature, share, or
invest further in the project.

## Actual

The differentiators exist in the game itself but aren't articulated anywhere for an outside reader
deciding whether this is worth their attention.

## Suggested next step

Add a short section to `docs/backlog/GTM-PLAN.md` (or a standalone doc) summarizing the game's
distinct features relative to typical browser snake clones, aimed at anyone evaluating or
promoting the project.
