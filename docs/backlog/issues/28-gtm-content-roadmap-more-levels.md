# 28. Plan a content roadmap: author 5-10 additional levels beyond the current 3

**Type:** gtm  
**Priority:** p2  
**Area:** levels  
**Labels:** gtm, priority: p2, area: levels

## Summary

The game currently ships exactly 3 levels (Afterglow Alley, Mirror Metro, Green Grass). A first release/launch with only 3 levels offers a very short play session, and (per the level-select overflow bug filed separately) the UI has not yet been proven to handle more than 3.

## Suggested next step

Draft a content roadmap: how many levels for a first release, what new mechanics or difficulty curve each batch should introduce, and use the level editor to author them. Sequence this after the level-select overflow bug fix so new levels do not immediately break the menu.
