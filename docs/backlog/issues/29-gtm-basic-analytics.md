# 29. Set up lightweight, privacy-respecting analytics (levels played, completion rate, session length)

**Type:** gtm  
**Priority:** p3  
**Labels:** gtm, priority: p3

## Summary

There is no analytics or telemetry of any kind in the codebase today — no way to know which levels players finish, where they quit, or how long a typical session lasts.

## Suggested next step

Add a minimal, privacy-respecting analytics integration (e.g. simple pageview/event counters) tracking level starts, level completions, and average session length, to inform which levels or mechanics need iteration after launch.
