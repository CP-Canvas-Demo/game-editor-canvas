# 30. Set up a feedback channel and a GitHub issue template for player-reported bugs

**Type:** gtm  
**Priority:** p3  
**Labels:** gtm, priority: p3

## Summary

There is no `.github/ISSUE_TEMPLATE/` in the repository, so player bug reports (once there are external players) have no structured format to follow, making triage harder.

## Suggested next step

Add a simple bug-report issue template (repro steps, expected vs actual, browser/OS) and a lightweight feedback channel (e.g. a pinned discussion thread or a simple in-app "report a bug" link) so early players have an obvious way to send structured feedback.
